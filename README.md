# 🎯 ENlearning Assistant
> **数据驱动的个性化 AI 英语导师系统 (v1.0)**

[![Pedagogy](https://img.shields.io/badge/Pedagogy-ZPD%20%7C%20i%2B1-orange)](https://en.wikipedia.org/wiki/Zone_of_proximal_development)
[![Logic](https://img.shields.io/badge/Logic-Data--Driven-blue)](#-核心算法)
[![Platform](https://img.shields.io/badge/Platform-Claude%20%2F%20GPT--4-green)](#-使用指南)

**ENlearning Assistant** 并非一个简单的聊天指令，而是一套完整的**英语教学操作系统**。它基于认知科学中的“最近发展区（ZPD）”理论，通过动态蓝思值（Lexile）调整算法和五文档底层架构，为用户提供极其精准、连续且可量化的英语习得体验。

---

## ✨ 核心亮点

### 1. 🔬 科学的习得闭环
系统严格遵循 **输入(i+1) → 内化(复现) → 输出(场景任务) → 反馈(量化批改) → 校准(算法更新)** 的闭环。拒绝碎片化学习，确保每一分钟的投入都有据可依。

### 2. 📊 动态难度校准 (Lexile Algorithm)
内置蓝思值动态调整公式。根据用户每周的**写作均分**和**任务完成率**，以 ±10L 为步长自动调整语料难度，确保学习材料始终处于用户的“理想挑战区”。

### 3. 🧠 颗粒度词汇追踪 (0.25 Step System)
将词汇熟练度量化为 **0.00 - 5.00**（0.25为一档）。通过“阅读识别、测验验证、主动输出”多维度提升熟练度，并结合艾宾浩斯曲线自动规划复习周期。

### 4. 📝 专业级写作批改
内置标准评分量表（Rubric），从内容、结构、语言、语法四个维度进行深度拆解，并提供地道表达升级建议（Chinglish 纠正）。

### 5. 🔗 内容连续性保障
每月固定主题，每周细分话题。通过文章间的逻辑链和词汇强制复现，实现跨周、跨月的内容延续，模拟真实语境下的语言沉淀。

---

## 🛠️ 技术架构：五文档系统 (5-Doc System)

系统通过五个独立维护的逻辑文档实现“长期记忆”与“个性化适配”：

*   **Doc1: 用户档案** (User Profile) - 存储蓝思值、兴趣标签、转化率、缺勤记录等核心数据。
*   **Doc2: 语块知识库** (Knowledge Base) - 基于“85% 缺口理论”动态生成的月度/周度学习大纲。
*   **Doc3: 个人词库** (Personal Vocab) - 每一个词条的熟练度权重与复习计划。
*   **Doc4: 难度校准算法** (Logic) - 执行量化评分到难度变迁的逻辑转换。
*   **Doc5: 资源库** (Resources) - 匹配当前水平的精/泛听力与阅读资源推荐。

## 📅 周常学习工作流

| 周期 | 任务类型 | 核心产出 |
| :--- | :--- | :--- |
| **周一** | 派发周包 | 主题播报、难度调整说明、课外书单推荐 |
| **周二** | 听说强化 | 定制短文、影子跟读指导、词块内化练习 |
| **周三** | 写作准备 | 主题阅读、写作 A 框架构思、蓝思值进阶语料 |
| **周四** | 写作攻坚 | 定制短文、写作初稿提交、周词汇测验(10题) |
| **周五** | 深度反馈 | 深度批改报告(Artifacts)、口语话题与评估 |
| **周末** | 复习巩固 | 错题复盘包、语法微课、词库熟练度更新 |

## 🚀 使用指南

### 环境建议
*   **推荐模型**：`Claude 3.5 Sonnet` (效果最佳) 或 `GPT-4o`。
*   **功能依赖**：需开启 **Artifacts** (用于生成报告) 和 **Documents/Project** 功能 (用于持久化数据)。

### 启动流程
1. 将本仓库中的 `ENlearning_Assistant_Prompt.md` 全部内容复制并粘贴至 AI 聊天框。
2. AI 将自动进入 **【阶段 0：冷启动流程】**。
3. 按照引导回答 5 个基本问题（水平、目标、兴趣等）。
4. 接收你的《初始评估报告》，开始第一周的学习！

## 📈 核心量化指标

系统通过以下指标监控学习成效：
*   **ΔL (蓝思值变化)**：反映语言理解能力的硬性增长。
*   **词汇转化率 (%)**：衡量“被动输入词汇”转化为“主动输出词汇”的效率。
*   **任务完成率 (%)**：监控学习习惯与执行力。
*   **写作/口语分阶均分**：反馈产出技能的综合表现。

---

## ⚠️ 注意事项
*   **补课机制**：若产生缺勤，系统会自动派发“精简补课包”，请优先完成微输出任务以重启进度。
*   **平台期**：若连续两周 ΔL=0，系统会切换策略并进行心理疏导，请保持耐心。
*   **Chinglish**：系统会重点标注中式思维表达，请关注每篇短文后的“地道表达升级”。
